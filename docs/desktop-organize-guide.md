# 桌面清爽化完整方案（Desktop Organization Guide）

> 基于全球调研（macOS 原生特性 + Windows 开源方案），结合本项目（桌面整理 / Desktop Organizer）现有能力，
> 形成一套完整的桌面文件整理、图标自定义、搜索增强方案。

---

## 一、核心问题

**现状**：桌面文件过多、图标混乱、找不到东西、视觉杂乱。

**目标**：让 Windows 桌面像 macOS 一样清爽——文件自动归类、图标美观统一、搜索快速精准、小组件实用。

---

## 二、macOS 桌面的核心设计哲学

| 哲学 | macOS 实现 | 本项目借鉴 |
|------|-----------|-----------|
| **自动化归类** | Stacks（按类型/日期/标签自动分组） | 集合组件 + 分类视图 |
| **标签化管理** | Finder Tags（颜色+名称，跨文件夹） | 集合组 + 颜色标签 |
| **智能文件夹** | Smart Folders（Spotlight 查询自动更新） | 快速导航 + Everything 集成 |
| **图标个性化** | 文件夹颜色/符号/Emoji 自定义（macOS Tahoe） | Lua 组件 + 图标自定义 |
| **桌面小组件** | Sonoma 桌面 Widgets（时钟/天气/日历） | 12 个内置 Lua 组件 |
| **台前调度** | Stage Manager（窗口自动排列） | 窗口平铺（Halves/Thirds/Quarters） |

## 三、文件整理策略

### 3.1 Stacks（堆叠）—— 自动归类

macOS Stacks 按以下维度自动分组桌面文件：

| 分组方式 | 说明 | 本项目实现 |
|---------|------|-----------|
| **按类型** | 图片/文档/视频/音频/压缩包/其他 | 集合组件 —— 创建"图片"集合，文件拖入自动分类 |
| **按日期** | 今天/昨天/本周/本月/更早 | 快速导航搜索 + 日期分组视图 |
| **按标签** | 工作/个人/紧急/已归档 | 集合组 —— 按项目/状态分组 |
| **按来源** | 下载/截图/编辑/共享 | 文件夹映射 —— 映射"下载"文件夹 |

**操作步骤**（使用本项目）：
1. 创建集合：右键桌面 → 新建集合 → 命名"文档"
2. 文件拖入：桌面文件直接拖入对应集合
3. 自动分类：结合桌面文件分类组件，按扩展名自动归类
4. 集合组：多个集合合并为标签页，如"工作|个人|项目"

### 3.2 智能文件夹（Smart Folders）—— 自动查询

macOS Smart Folders 本质是保存的搜索查询，实时更新。

**本项目实现**：
- 快速导航（Spotlight 风格搜索）：Win+K 快捷键，搜索桌面/文件/应用
- Everything 集成：全局文件搜索，支持正则/大小/日期过滤
- 桌面文件分类组件：自动按类型分组显示桌面文件

### 3.3 文件命名规范（最佳实践）

```
2026-08-22_项目名_文档类型_版本.pdf
例：2026-08-22_桌面整理_方案文档_v1.0.pdf
```

**命名原则**：
- 日期前缀：YYYY-MM-DD，便于排序
- 项目名：下划线连接
- 文档类型：方案/报告/合同/发票
- 版本：v1.0/v2.0

## 四、图标自定义策略

### 4.1 文件夹颜色自定义（macOS Tahoe 参考）

macOS Tahoe 新增文件夹颜色自定义：右键文件夹 → 自定义 → 选择颜色/符号/Emoji。

**Windows 实现**：
- 右键文件夹 → 属性 → 自定义 → 更改图标
- 使用 IconPackager/Stardock IconPackager 批量更换
- 使用 CustomizerGod 自定义系统图标

**本项目增强**：
- 桌面文件分类组件：自动为不同类型文件显示不同图标
- 集合组件：支持自定义颜色和图标
- 集合组标签页：不同标签页用不同颜色标识

### 4.2 文件预览缩略图

macOS 在桌面直接显示文件内容预览（PDF 第一页/图片缩略图/视频封面）。

**Windows 实现**：
- 资源管理器 → 查看 → 超大图标（自动显示缩略图）
- 使用 QuickLook（空格预览，macOS 风格）
- 使用 Seer（类似 QuickLook 的 Windows 版）

## 五、搜索增强策略

### 5.1 Spotlight 风格搜索

macOS Spotlight（Cmd+空格）：全局搜索文件/应用/设置/计算器/翻译。

**本项目实现**（已具备）：
- 快速导航（Win+K）：搜索桌面项目、应用、Everything 文件结果
- 支持分类筛选（桌面/文件夹/应用/文件）
- 搜索框放大镜图标（macOS Spotlight 风格）

**增强建议**：
- 添加搜索历史记录
- 添加搜索建议/自动补全
- 添加文件预览窗格（选中结果后显示文件内容）

### 5.2 Everything 集成增强

- 支持正则表达式搜索
- 支持按大小/日期/类型过滤
- 支持搜索结果直接拖放到集合

| 组件 | 功能 | macOS 对应 |
|------|------|-----------|
| 指针时钟 | 模拟时钟 | ✅ 时钟小组件 |
| 数字时钟 | 数字时间+日期 | ✅ 时钟小组件 |
| 月历 | 月视图日历 | ✅ 日历小组件 |
| 天气 | 实时天气+温度 | ✅ 天气小组件 |
| 世界时钟 | 多城市时间 | ✅ 世界时钟小组件 |
| 系统监控 | CPU/内存/磁盘 | ✅ 活动监视器 |
| 媒体控制 | 播放/暂停/音量 | ✅ 音乐小组件 |
| 便签 | 文字记录 | ✅ 便签小组件 |
| 番茄钟 | 工作/休息计时 | ✅ 计时器小组件 |
| RSS 阅读器 | 新闻订阅 | ✅ 新闻小组件 |
| 快速启动 | 应用快捷方式 | ✅ 启动台 |
| 桌面文件分类 | 文件自动归类 | ✅ 文件小组件 |

**布局建议**：
- 屏幕右上角：时钟 + 天气
- 屏幕右下角：日历 + 系统监控
- 屏幕左侧：快速启动 + 便签
- 屏幕中央：保持干净（只放当前工作文件）

## 七、窗口管理策略

### 7.1 窗口平铺（macOS Sequoia 参考）

macOS Sequoia 新增窗口平铺：拖拽窗口到屏幕边缘自动吸附。

**本项目已实现**（window_tiling.h）：
- Halves（左右半屏）
- Thirds（三等分）
- Quarters（四角四等分）
- PrimaryFocus（2/3 + 1/3 主焦点）

### 7.2 Stage Manager（台前调度）

macOS Stage Manager 自动将窗口排列在屏幕左侧，点击切换。

**本项目增强**：
- Dock 运行指示器：显示哪些应用正在运行
- 窗口预览：Dock 悬停显示窗口缩略图
- 快速切换：点击 Dock 图标切换到对应窗口

## 八、动态壁纸策略

### 8.1 macOS 动态壁纸

macOS Mojave+ 支持动态壁纸：根据时间自动切换（日出→白天→日落→夜晚）。

**本项目已实现**（app_wallpaper.cpp）：
- WinDynamicDesktop 兼容 JSON 主题格式
- 四段轮换：日出/白天/日落/夜晚
- 支持 JPG/PNG 图片目录
- 15 分钟检查间隔

**使用方法**：
1. 准备壁纸图片（同一场景的不同时间段）
2. 创建 theme.json（指定各时段图片列表）
3. 在设置中启用动态壁纸主题

## 九、视觉风格策略

### 9.1 玻璃材质（Liquid Glass）

macOS 的毛玻璃效果：Dock/菜单栏/通知中心使用半透明模糊背景。

**本项目已实现**：
- 三级模糊（8px/20px/36px，按元素大小自动选择）
- 流动高光（对角渐变光带，8 秒周期）
- 边缘折射（径向渐变折射效果）
- 深色/浅色主题自动切换

### 9.2 圆角系统

macOS 的圆角：所有 UI 元素使用统一的圆角系统。

**本项目已实现**：
- Fixed 圆角（5px/8px/11px/18px）
- Capsule 圆角（半高，用于按钮/标签）
- 同心圆角（内层圆角 = 外层圆角 - 内边距）

### 9.3 排版系统

macOS 使用 SF Pro 字体，统一的字号/字重/行高体系。

**本项目已实现**：
- 字体回退（SF Pro → Inter → Segoe UI Variable）
- Dynamic Type（跟随系统字号缩放）
- 负字间距（Apple tight 风格）

## 十二、总结

**桌面清爽化的核心原则**：

1. **自动化优先**：让系统自动归类文件，而不是手动整理
2. **标签化管理**：用颜色/标签跨文件夹组织，而不是嵌套文件夹
3. **搜索为王**：与其整理文件夹，不如学会高效搜索
4. **视觉统一**：统一的图标/颜色/排版风格，让桌面美观
5. **小组件辅助**：时钟/天气/日历放在桌面，减少窗口切换

**一句话总结**：
> macOS 的桌面不是靠"整理"变干净的，而是靠**自动化归类 + 标签化管理 + 高效搜索 + 统一视觉**让桌面**看起来**干净。
> 本项目已具备以上全部能力，只需正确配置使用。
